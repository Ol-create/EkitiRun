# EkitiRun

Race platform for the Ekiti Marathon: free runner registration, sponsor payments, checkpoint timing and live runner tracking.

- Team task split: [docs/tasks/README.md](docs/tasks/README.md) (PDF: [docs/ekitirun-task-split.pdf](docs/ekitirun-task-split.pdf))
- API contract: [docs/api-contract.md](docs/api-contract.md)
- Task board: GitHub Projects → **EkitiRun v1**

## Project structure

Each folder says who owns it. Work only in the folders your task card names.

```
ekitirun/
├── docker-compose.yml          # Postgres, Redis, API, worker
├── package.json                # pnpm workspace scripts (dev, build, gen:api)
├── docs/                       # task split, API contract
├── scripts/                    # GitHub card script
└── apps/
    ├── api/                    # FastAPI backend
    │   ├── app/
    │   │   ├── main.py         # creates the app, mounts every router under /api/v1
    │   │   ├── core/           # config, database, shared deps (Lead)
    │   │   ├── models/         # SQLAlchemy models (Lead only)
    │   │   ├── modules/        # one folder per feature: router, schemas, service, tests
    │   │   │   ├── auth/           Lead (E3)
    │   │   │   ├── registrations/  Lead (E4)
    │   │   │   ├── categories/     Lead example module + Backend (B3)
    │   │   │   ├── runners/        Backend (B3)
    │   │   │   ├── sponsors/       Backend (B1, B2)
    │   │   │   ├── payments/       Lead (E5)
    │   │   │   ├── scans/          Lead (E8)
    │   │   │   ├── timing/         Lead (E9)
    │   │   │   ├── results/        Lead (E9, E11)
    │   │   │   └── route/          Lead (E10)
    │   │   ├── workers/        # ARQ background jobs: PDFs (Lead, E6)
    │   │   └── templates/pdf/  # invoice and receipt templates (Backend, B4)
    │   ├── alembic/            # migrations (Lead only)
    │   ├── scripts/            # seed data, PDF preview
    │   └── tests/
    └── web/                    # Next.js frontend
        ├── app/                # one folder per page (URL)
        │   ├── register/           Frontend 1 (F1.1, verify: F1.2, success: F1.3)
        │   ├── sponsors/           Frontend 1 (F1.4)
        │   ├── results/            Frontend 2 (F2.1)
        │   ├── track/              Frontend 2 (F2.2, [bib]: F2.2 + F2.3)
        │   └── scanner/            Lead (E7)
        ├── components/         # components grouped by the same names as app/
        ├── lib/
        │   ├── api.ts          # typed API client (Lead), use it for every API call
        │   ├── api-types.ts    # generated by `pnpm gen:api`, never edit by hand
        │   ├── tracking.ts     # position estimate (Lead, E10)
        │   └── format.ts       # ₦ and time formatting helpers (shared)
        └── public/
```

Full setup instructions come with ticket E1.
